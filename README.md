# Greenfield Community Clinic

A small, hand-crafted static website for a fictional neighborhood clinic. It is an intentionally inaccessible demo target for CodeGuard, so it includes a documented set of planted, fixable accessibility issues alongside accessible control-group content.

## Run it

```sh
npm install
npm start
```

Open `http://localhost:3000`. Run the structural tests with:

```sh
npm test
```

The site has no build step and its illustrations are local SVGs. The optional Google Fonts link will gracefully fall back to system fonts when offline.
